환자 MRI 3D 모형 · 전외측 포털 · 30° 사시경 · figure-4 근사  |  이식편 비교로 돌아가기

근사 모형이다. 대퇴는 후과 원 중심 축으로 강체 회전(롤백 무시)하고, 활막·지방체 변형·관절액은 없다. 터널 기본 경사·방위는 임의 시작값이므로 실제 가이드 각도로 맞춰서 볼 것.

기구는 단순 형상이다. 탐침·파지기·관통기·조준 가이드는 실제 기구 사진의 자로 길이를 맞췄고, 셰이버·큐렛은 표준 치수다. 경과 기구는 뼈·반월상연골에 닿으면 멈추지만 연부조직 장력은 아직 없다.

  • 관절경(마우스): 왼쪽 끌기 = 경 방향, 오른쪽 끌기(좌우) = 30° 렌즈 회전, 휠 = 깊이
  • 기구(한 손 키보드): W/A/S/D = 방향, Q/E = 회전, 2 = 전진, X = 후퇴(Shift ×5). 버튼은 누르고 있으면 반복
  • 뼈에 닿으면 멈추고, 반월상연골·이식편은 3 mm까지 눌림
  • 포털 높이 = 외측 고평부 관절면 위 거리, 슬개건에서 = 슬개건 가장자리로부터의 거리
  • Shift + 클릭(두 화면 모두) = 선택한 터널 입구를 그 자리로 이동
  • 방위 0° = 전방, + = 내측. 경사 = 고평부와 이루는 각
  • 골교 = 두 터널 벽 사이 최소 거리(경골 안 전 구간)
