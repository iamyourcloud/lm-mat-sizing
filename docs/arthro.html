근사 모형이다. 대퇴는 후과 원 중심 축으로 강체 회전(롤백 무시)하고, 활막·지방체 변형·관절액은 없다. 터널 기본 경사·방위는 임의 시작값이므로 실제 가이드 각도로 맞춰서 볼 것.

  • 관절경 화면: 끌기 = 경 방향, 휠 = 깊이, Q/E = 렌즈 회전
  • 포털 높이 = 외측 고평부 관절면 위 거리, 슬개건에서 = 슬개건 가장자리로부터의 거리
  • Shift + 클릭(두 화면 모두) = 선택한 터널 입구를 그 자리로 이동
  • 방위 0° = 전방, + = 내측. 경사 = 고평부와 이루는 각
  • 골교 = 두 터널 벽 사이 최소 거리(경골 안 전 구간)
